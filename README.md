# ✈️ Airline Data Analysis Project
# Project Overview
This project focuses on analyzing airline data using multiple tools and technologies including Excel, Python, SQL, and Power BI.
The goal was to clean, transform, analyze, and visualize the data to extract meaningful business insights

🛠️ Tools & Technologies Used
Python
Pandas & NumPy
Matplotlib & Seaborn
MySQL
Excel
Power BI
DAX Measures

📂 Project Workflow
1.Data Exploration & Cleaning (Python)
Performed Exploratory Data Analysis (EDA)
Handled missing values
Removed duplicates
Detected and treated outliers
Cleaned and transformed the dataset using Python
2. Export Cleaned Data
Saved the cleaned dataset as CSV files for further processing
3.SQL Database Design
Imported the dataset into MySQL
Split the data into two related tables
Applied normalization concepts
Used:
JOINs
Queries
Filtering
Aggregations
4. Data Warehouse & Star Schema
Built a Data Warehouse model
Designed a Star Schema structure
Created Fact and Dimension tables for better analytical performance
5. Excel Reporting
Imported SQL data into Excel
Built Pivot Tables
Created charts and analytical reports
6.Power BI Dashboard
Connected Power BI with SQL Database
Built interactive dashboards
Created DAX Measures
Visualized KPIs and business insights

 #Key Insights
Airline performance trends
Delay analysis
Customer and flight patterns
Operational efficiency insights
Revenue and booking analysis

Practice the complete Data Analysis workflow
